制作你的游戏快速开始API

SDK API / 公共接口

The installed package's declarations are the source for exact signatures. 使用安装包中的类型声明查看完整参数与返回类型；编辑器可直接跳转定义。下方完整模块／出口表由当前 SDK 契约生成，随下载包更新，不根据本仓游戏的引用猜测公共能力。

常用入口 / Common entry points

  • @bgparty/sdk/core：defineGame、GameDefinition、种子随机数、规则与 bot 类型。Pure rules, schemas and bots.
  • @bgparty/sdk/ui：GameScreen、PlayerStrip、PhaseBanner、DeltaNumber、Texture、界面参数类型。Layout and common view props.
  • @bgparty/sdk/i18n、messages：useT、useGameT、语言与 GameMessages 扩展。Localization and message augmentation.
  • @bgparty/sdk/assets：gameAssetUrl、sharedAssetUrl。Resolve installed assets to sandbox URLs.
  • @bgparty/sdk/storage：readGameStorage、writeGameStorage，要求 sdkApi: 2。Committed local progress with revision conflict handling.
  • @bgparty/sdk/icons、player-colors、avatars：平台公开图标、座位色和头像。Public presentation helpers.
  • @bgparty/sdk/fx/*、drawing/*、three/*：按需接入演出、绘画与 3D 支持。Optional effects, drawing and resilient 3D.

核心流程示例见 中文开发教程 / English development guide。准确的输入、输出和可选回调以对应 .d.ts 为准；不直接导入 types/ 下的内部路径。

Game modules run in the host sandbox. 不要在 Node 里执行 SDK 的 empty.mjs。UI/API 1 游戏可继续使用兼容 SDK；采用新存储接口时在 game.json 顶层声明 sdkApi: 2。SDK npm 包版本、最低 API 与游戏存档版本分别维护。
